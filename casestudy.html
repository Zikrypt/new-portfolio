01
RECRUITMENT · SAAS

Pekamy
Freshminds

Pekamy Fresh Minds is a talent-connection platform built to bridge the gap between graduates, interns, and companies in search of skilled individuals. This case study explores the end-to-end process of designing and developing the platform — from crafting a clean, user-focused interface to building a secure backend system.

The website features a smooth onboarding experience where users can sign up, register, and create profiles to showcase their skills, while companies can browse, shortlist, and connect with potential candidates. The goal was to deliver a modern, responsive, and efficient platform that empowers young professionals and simplifies the hiring process for organizations.

As the CTO and lead developer, I handled both front-end and back-end development. The front-end was built using React, CSS, and JavaScript, while the back-end was powered by PHP and MySQL to manage user registration, authentication, and data storage securely.

02
AUTOMOTIVE · COMMERCE

Everyday
Motors

Everyday Motors is a modern automotive company focused on redefining car sales and service accessibility through technology. This case study highlights the design and development of their digital platform — built to showcase available vehicles, streamline customer inquiries, and enhance the overall user experience.

As the lead developer, I was responsible for both front-end and back-end implementation. I designed a visually appealing, responsive interface using HTML, CSS, and JavaScript, and integrated PHP and MySQL to handle vehicle data, customer registrations, and inquiry forms securely.

The platform allows users to sign up, view detailed car profiles, and send direct purchase or service requests — all within a clean, intuitive environment. Everyday Motors now operates with an efficient online system that improves lead generation and enhances brand credibility.

ROLE LEAD DEV YEAR 2025 STACK JS · PHP · MYSQL
03
BLOCKCHAIN · AUTOMATION

Solana
Copy Bot

The Solana Copy Trading Bot is a powerful automation tool designed to mirror transactions from specific whale wallets on the Solana blockchain. This case study explores the development of a secure, efficient, and scalable Telegram-integrated bot that allows traders to automatically replicate successful trades in real-time.

The bot was built using Node.js and integrated with the Solana Web3.js library to fetch and execute blockchain transactions. The Telegram interface was implemented using the Telegram Bot API, providing users with simple commands for wallet linking, copy settings, and real-time notifications. Security was prioritized through encrypted private key storage and restricted API access.

This project deepened my understanding of blockchain development, automation, and secure API integration — building reliable real-time systems that process live on-chain data efficiently.

ROLE SOLO DEV YEAR 2025 STACK NODE · WEB3.JS · TELEGRAM API
04
MOBILE · SECURITY

Secure
VPN App

The Secure VPN Mobile App project was developed to bring flexible VPN connectivity to both iOS and Android users using the SoftEther VPN protocol. This case study highlights the process of building a cross-platform mobile solution with a smooth, privacy-focused experience and modern UI.

The app was built using Flutter for cross-platform compatibility, ensuring consistent performance on both platforms. The backend integration leveraged SoftEther's open-source libraries combined with secure API endpoints to manage server lists, authentication, and connection logs. Additional focus was placed on connection stability, low latency, and end-to-end encryption.

This project strengthened my experience in network security, mobile app development, and open-source system adaptation — resulting in a reliable, enterprise-grade VPN solution accessible directly from mobile devices.
